## Adding future deliverables

To keep this section consistent as more deliverables are added:

1. Add the new Markdown file to the `docs/04-Deliverables/` folder.
2. Add one row to the table on this page.

Following the existing filename pattern, such as `02-Deliverable_4.7_...`, will keep the files ordered and easy to scan.
